 Git Bash: Lệnh rất ngắn gọn, gộp nhiều chức năng vào một công cụ (grep) và dùng ký hiệu toán học (>>) để ghi file. Viết rất nhanh nếu đã quen. 

PowerShell: Lệnh dài hơn nhưng đọc y như một câu tiếng Anh đầy đủ (Get -> Select -> Out). Rất rõ ràng, mạch lạc và dễ hiểu cho người mới đọc vào (không cần phải nhớ ký hiệu >> hay -r nghĩa là gì).
